🧱 Часть 1. Что такое таблица?
Представь тетрадку в клеточку. Таблица — это такая же сетка из клеточек, только в интернете. Каждая клеточка называется ячейка.

Вот как выглядит таблица:

text
┌─────────┬──────────────┐
│  День   │    Урок      │   ← шапка (заголовки)
├─────────┼──────────────┤
│   Пн    │  Математика  │   ← строка 1
│         │  Русский     │
├─────────┼──────────────┤
│   Вт    │  Русский     │   ← строка 2
└─────────┴──────────────┘
🏷️ Часть 2. Какие теги нужны?
В HTML для таблиц есть специальные теги. Вот они — как детали конструктора:

Тег	Что означает	Простыми словами
<table>	Table — таблица	Обёртка всей таблицы. Как обложка тетрадки 📘
<thead>	Table Head — голова	Верхняя часть — шапка с названиями колонок
<tbody>	Table Body — тело	Основная часть — где сами данные
<tr>	Table Row — строка	Одна горизонтальная строка таблицы ➡️
<th>	Table Header — заголовок	Жирная ячейка (для названий). Обычно в шапке
<td>	Table Data — данные	Обычная ячейка с информацией
🍰 Часть 3. Разбираем наш пример
Вот наш код целиком — а ниже разберём каждую строчку:

html
<table>
    <thead>
        <tr>
            <th>День</th>
            <th>Урок</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <th>Пн</th>
            <td>Математика<br>Русский<br>Английский</td>
        </tr>
        <tr>
            <th>Вт</th>
            <td>Русский<br>Китайский</td>
        </tr>
    </tbody>
</table>
🔍 Что тут происходит?
1️⃣ <table> — начинаем таблицу.

💡 Это как сказать браузеру: «Эй, сейчас будет таблица!»

2️⃣ <thead> — шапка таблицы.

💡 Здесь будут названия колонок.

3️⃣ <tr> — первая строка (шапки).

💡 <tr> = Table Row = строка.

4️⃣ <th>День</th> и <th>Урок</th> — две ячейки-заголовка.

💡 <th> делает текст жирным и по центру. Это для названий.

5️⃣ Закрываем </tr> и </thead> — шапка готова!

6️⃣ <tbody> — начинаем основную часть.

7️⃣ Первая строка данных:

html
<tr>
    <th>Пн</th>
    <td>Математика<br>Русский<br>Английский</td>
</tr>
<tr> — новая строка

<th>Пн</th> — ячейка с понедельником (можно <td>, но <th> выглядит жирнее)

<td>...</td> — ячейка с уроками

<br> — перенос строки (чтобы уроки были друг под другом)

8️⃣ Вторая строка — то же самое, но для вторника.
